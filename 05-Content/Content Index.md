# 内容创作索引

## 生产流程

- [[05-Content/Ideas/Ideas Index|创意]] — 角度、问题、钩子和证据缺口。
- [[05-Content/Scripts/Scripts Index|脚本]] — 草稿和可直接制作的脚本。
- [[05-Content/Published/Published Index|已发布]] — 已发布作品和效果记录。

## 工作流

1. 记录创意，并明确受众和问题。
2. 链接支持性研究，识别缺失证据。
3. 使用 [[90-Templates/Content Brief Template|内容简报模板]] 创建内容简报。
4. 在 `Scripts` 中撰写草稿。
5. 发布后将最终版本移入 `Published`，记录网址、日期、平台和经验。

在 [[98-AI-Context/Platform Strategy|平台策略]] 中确认渠道选择前，不创建平台专属目录。
