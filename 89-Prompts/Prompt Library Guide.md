# 提示词库指南

## 何时保存提示词

- 可以在多个任务中复用；
- 可以清楚描述输入和预期输出；
- 可以评估执行效果；
- 包含长期有效的工作流知识，而不是一次性对话。

## 必填字段

- 用途；
- 如有限制，注明兼容的 Agent 或模型；
- 必需输入；
- 提示词正文；
- 输出规范；
- 质量检查；
- 版本和变更记录。

## 分类规则

每个提示词只能放在一个分类目录中。次要用途通过主题标签和链接表达。

## 改进循环

1. 在有代表性的任务上运行提示词。
2. 记录失败模式。
3. 每次只修改一个关键要素。
4. 重新测试。
5. 更新版本和变更记录。

绝不保存 API 密钥、令牌、个人秘密或原始私人对话。
