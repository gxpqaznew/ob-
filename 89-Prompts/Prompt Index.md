# 提示词索引

## 分类

- `Research` — 来源分析、证据收集和比较。
- `Workflow` — 可重复执行的多步骤操作流程。
- `Automation` — 脚本、集成和自动化 Agent。
- `Business` — 战略、市场、产品和商业化。
- `Content` — 创意、简报、编辑和内容改编。
- `Video Script` — 钩子、大纲、旁白和镜头计划。
- `Cover Design` — 缩略图、封面和视觉方向。

新提示词使用 [[90-Templates/Prompt Template|提示词模板]]，并遵循 [[89-Prompts/Prompt Library Guide|提示词库指南]]。
