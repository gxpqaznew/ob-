# 研究资料导入指南

## 导入入口

- 浏览器文章：使用 Web Clipper 的 `研究资料收集` 模板。
- Markdown 下载：保存到 `00-收件箱/已下载`。
- 文件和图片：放入 `00-收件箱/附件`。
- 临时笔记：先创建在 `00-收件箱`，随后进行分拣。

## 必须保留的来源信息

尽可能保留来源提供的以下信息：

- 标题；
- 来源网址；
- 作者或发布者；
- 发布时间；
- 收集时间；
- 完整原文。

绝不覆盖 `已下载` 中的原始文件。运行研究资料清洗器，生成独立的清洗副本。

## 运行清洗器

在 PowerShell 中运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\98-AI-上下文\自动化\研究资料清洗器.ps1"
```

只有在需要把清洗后的副本移动到主研究分类时，才添加 `-Promote`。
