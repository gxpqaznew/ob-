# 收件箱工作台

你不需要翻文件夹。平时只打开这个页面即可。

## 新收藏的资料

```query
path:"00-收件箱/已下载"
```

## 已清洗、待确认的资料

```query
path:"00-收件箱/已清洗"
```

## 怎么处理

1. 没价值：归档或删除。
2. 有参考价值：清洗后放入 `04-研究`。
3. 能写成内容：在 `05-内容创作/创意` 建立创意并链接原资料。
4. 能形成任务：链接到对应的项目状态页。

## 常用入口

- [[知识库主页|返回知识库主页]]
- [[00-收件箱/研究资料分拣指南|查看分拣规则]]
- [[04-研究/研究索引|进入研究库]]
- [[05-内容创作/内容索引|进入内容创作]]
