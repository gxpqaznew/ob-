## Project standard

Every project is a direct child directory of `06-Projects` and contains `Project-Status.md`. Create one with:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\98-AI-Context\Automation\New-Project.ps1" -Name "Project Name"
```

The project status note records current state, completed work, outstanding tasks, next action, risks, and decisions.
