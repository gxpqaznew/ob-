# Best Practices

- Keep raw sources immutable and create cleaned derivatives.
- Prefer links to duplicated notes.
- Update project status after meaningful progress.
- Record decisions with rationale and date.
- Run the audit after structural or bulk-import changes.
- Commit small, reviewable changes and never commit secrets.
