# 网页收集替代工作流

> MarkDownload 原版 Chrome 扩展已因不符合当前扩展最佳实践而停用。不要绕过 Chrome 的保护。本 Vault 改用已导入的 **Obsidian Web Clipper / 研究资料收集** 模板。

## 流程

```text
网页
  ↓ Obsidian Web Clipper / 研究资料收集
00-收件箱/已下载
  ↓ 研究资料清洗器.ps1
00-收件箱/已清洗
  ↓ 分拣 / -Promote
04-研究/<一个主分类>
  ↓
主题标签 + 主题中心链接
```

## 收集设置

- 目标目录：`00-收件箱/已下载`
- 保留标题、来源网址、作者、收集时间和文章正文。
- 使用已导入的 `研究资料收集` 模板。
- 未经确认不覆盖现有文件。

无需安装 MarkDownload。

## 清洗

```powershell
Set-Location -LiteralPath "C:\ob仓库\ob仓库"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\98-AI-上下文\自动化\研究资料清洗器.ps1"
```

检查分类规则后，如需直接归入研究目录：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\98-AI-上下文\自动化\研究资料清洗器.ps1" -Promote
```

## 保证

- 永不编辑原始来源文件；
- 清洗输出记录来源路径和 SHA-256 哈希；
- 能识别时保留标题、作者、网址、发布日期和收集日期；
- 保守格式化会识别常见标题和编号列表；
- 长段落可以增加换行，但不改写或删除原文；
- 根据 `研究分类.json` 添加主题标签和主题中心链接。
