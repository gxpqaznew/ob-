# AI Context Maintenance Rules

Files in this directory define current operating context, not raw research or chat history.

- Keep statements concise and evidence-based.
- Mark unknown personal information as `needs-input`.
- Update `Current Focus.md` when priorities materially change.
- Update `Knowledge Map.md` after major imports or taxonomy changes.
- Put durable personal preferences in `97-AI-Memory/User Preferences.md`.
- Put historical decisions in `97-AI-Memory/Decisions.md`.
- Never place credentials, tokens, or private keys here.
