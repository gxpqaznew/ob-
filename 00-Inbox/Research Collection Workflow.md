# 研究资料收集工作流

```text
Web Clipper / 手动笔记
                  ↓
       00-Inbox/Downloaded
                  ↓
          研究资料清洗器
                  ↓
         00-Inbox/Cleaned
                  ↓
       人工或 Agent 分拣
                  ↓
 04-Research/<一个主分类>
                  ↓
      主题标签 + 内部链接
                  ↓
 主题中心 / 项目 / 内容创作
```

## 不可违反的规则

- `Downloaded` 保存不可修改的原始证据。
- 清洗只改善 Markdown 结构，不删除内容，也不进行总结。
- 每篇正式研究笔记只能有一个主分类，但可以包含多个主题标签。
- 项目和内容通过链接引用研究资料，不复制原文。
